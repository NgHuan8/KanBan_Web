# Kanban Collaboration Front-end

Front-end SPA cho hệ thống cộng tác làm việc theo thời gian thực.

## Công nghệ hiện tại

- React.
- TypeScript.
- Vite.
- React Router.
- CSS và CSS Modules.

## Chạy local

```bash
npm install
npm run dev
```

Tạo file `.env` từ `.env.example` khi bắt đầu tích hợp REST API.

## Kiểm tra

```bash
npm run build
npm run lint
```

Project hiện chỉ chứa scaffold, routing, layout và các page placeholder. Authentication, REST API, Kanban, realtime và collaborative editor chưa được triển khai.
